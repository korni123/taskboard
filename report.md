## Лабораторна 4. Git у терміналі

1. Що змінилося у виводі git status після git add?
Файл перейшов зі списку Untracked у зелений список Changes to be committed. Тобто він потрапив в індекс і готовий до commit.

2. Що показує git diff?
Він показує, що змінилось у файлах після останнього commit. Рядки з плюсом додані, рядки з мінусом видалені.

3. Чим відрізняється git switch main від git merge?
git switch main лише переходить на гілку main. git merge вливає зміни з іншої гілки в ту, на якій я зараз.

4. Чому виник конфлікт і як ти його розв'язав?
Я змінив один і той самий рядок із заголовком у двох гілках по-різному, і Git не зміг сам вибрати. Я відкрив index.html, прибрав службові рядки <<<<<<<, ======= і >>>>>>> та об'єднав обидва варіанти в один заголовок. Потім зробив git add і commit.

5. Скільки commit-ів у твоїй історії?
